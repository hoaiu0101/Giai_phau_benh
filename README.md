## Lưu ý đáp án

Ba file gốc **không có đáp án đánh dấu**. Đáp án trong app được chọn theo kiến thức giải phẫu bệnh chuẩn và đã rà soát lại toàn bộ 75 câu.

- **Câu 19** – đã sửa đáp án thành “Dãn mạch – dịch thoát mạch – hoá hướng động” (sưng = phù viêm + thấm nhập tế bào; tăng chuyển hoá giải thích triệu chứng nóng).
- **Câu 14, 38, 42** – dễ tranh luận, có gắn nhãn ⚠ trong app. Câu 38 có 2 phương án đúng trong đề gốc.

Nên đối chiếu những câu này với slide/giảng viên.

## Deploy GitHub Pages

1. Tạo repo mới (ví dụ `giai-phau-benh`).
2. Upload toàn bộ: `index.html` + `logo.jpg` + `README.md` + `.nojekyll`.
3. Settings → Pages → branch `main`, folder `/ (root)`.
4. Truy cập: `https://<username>.github.io/giai-phau-benh/`
